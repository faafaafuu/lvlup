# Как поставить Level Up на iPhone без платного аккаунта

## 1. Сервер разбора (необязательно, но голос понимается лучше)

На сервере, из корня репозитория:

```bash
npm ci
npm run build
cp apps/api/.env.example apps/api/.env   # заполнить API_TOKEN и ANTHROPIC_API_KEY
cd apps/api && set -a && . ./.env && set +a && npm start
```

- `API_TOKEN` — любой длинный случайный токен, он же вводится в приложении (Настройки → Распознавание).
- Порт по умолчанию 3100. Наружу лучше отдавать через https (nginx/caddy), токен идёт в заголовке.
- Без сервера приложение работает на офлайн-разборе прямо в телефоне.

Проверить качество разбора на эталонных фразах: `npm run eval -- anthropic` (или `openai`, `ollama`, `heuristic`).

## 2. Сборка IPA в Codemagic

1. Залить репозиторий на GitHub (приватный).
2. В Codemagic: Add application → репозиторий → тип «codemagic.yaml».
3. Запустить workflow `ios-unsigned`. Артефакт — `LevelUp.ipa` (подписи нет, это нормально).

## 3. Установка через SideStore

1. Один раз поставить SideStore на iPhone (нужен компьютер и бесплатный Apple ID, по инструкции SideStore).
2. Открыть `LevelUp.ipa` в SideStore → он подпишет приложение твоим Apple ID и установит.
3. Бесплатная подпись живёт 7 дней — SideStore продлевает сама, если раз в неделю открыть её с включённым VPN-туннелем.

Ограничения бесплатного Apple ID: максимум 3 сайдлоад-приложения, нет удалённых push
(у нас только локальные напоминания — работают). HealthKit может не пережить переподпись:
если в Настройках переключатель «Здоровье» не включается — шаги и сон вводятся на экране «Прогресс».

## Быстрый цикл разработки без сборки

```bash
cd apps/mobile && npx expo start --tunnel
```

QR-код открывается в **Expo Go** из App Store. Работает всё, кроме нативного голоса и HealthKit:
вместо микрофона — текстовый ввод (а в клавиатуре iPhone есть кнопка диктовки).
