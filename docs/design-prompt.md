# Промпт для дизайна Level Up

Скопируй всё ниже линии в дизайн-инструмент (Claude, Figma Make, v0, Galileo и т. п.) или отдай дизайнеру.
Раздел «Формат результата» в конце — то, что нужно разработке, чтобы перенести дизайн в код без пересказа.

---

## Роль и задача

Ты — продуктовый дизайнер мобильных игр и health-приложений. Спроектируй UI мобильного приложения
**Level Up** для iPhone: трекер питания и активности в виде лёгкой RPG. Пользователь прокачивает
своего героя, записывая еду голосом, проходя шаги и выполняя ежедневные квесты.

Главная ценность: **запись еды голосом за 10 секунд**. Всё в интерфейсе подчинено тому, чтобы от
открытия приложения до «Записано» было минимум действий. Игра — награда за запись, а не препятствие.

## Аудитория

- 25–45 лет, хотят похудеть или подтянуться, бросали обычные трекеры из-за скуки и ручного ввода.
- Любят прогресс, уровни, достижения, но не обязательно хардкорные геймеры.
- Язык интерфейса — **русский**.

## Стиль

- Минимализм + игровые акценты: чистые экраны, яркие акцентные цвета, прогресс-бары, бейджи.
- Взрослая RPG-эстетика, **не детская**: никаких мультяшных зверушек и кислотного хаоса.
  Референсы по настроению: Duolingo (сочность наград), Apple Fitness (кольца, ясность),
  Habitica (RPG-обёртка), Finch (тёплый персонаж).
- **Тёмная тема — основная**, светлая — обязательная вторая.
- «Сочные» награды: конфетти, вспышки, отскоки цифр опыта. Но анимация не блокирует ввод дольше 1.5 с.

## Этические ограничения (обязательно)

- Тело героя на любой стадии выглядит **довольным и симпатичным**. Никакого стыда, «до/после»
  с грустным толстым персонажем, никаких слов «жир», «лишний вес», «сорвался».
- Превышение нормы калорий — нейтральный цвет (не красный «ошибка»), формулировки вроде «чуть выше плана».
- Пропуск дня — мягко: «Огонь серии погас, но герой ждёт» вместо наказаний.

## Платформа и сетка

- iPhone, макеты на 390×844 (iPhone 14/15). Учитывай safe area, Dynamic Island, домашний индикатор.
- Сетка 4 pt, боковые поля 16–20 pt. Тач-зоны не меньше 44×44 pt.
- Шрифт — системный SF Pro (поддерживает кириллицу), допускается один акцентный дисплейный шрифт
  с кириллицей для цифр уровня/XP (укажи, какой, и запасной вариант).
- Контраст текста — WCAG AA в обеих темах.

## Навигация

Таб-бар из 4 вкладок:
1. **Герой** (главная)
2. **Дневник**
3. **Прогресс**
4. **Награды** (квесты, достижения, гардероб)

Настройки — иконка шестерёнки в шапке главного экрана.

## Экраны и состояния

Для каждого экрана нужны тёмная и светлая версии, пустое состояние и ошибка, где применимо.

### 1. Онбординг (5 шагов, прогресс-точки сверху, каждый шаг можно пропустить, кроме параметров)
1. **Приветствие**: герой машет, оффер «Прокачай себя. Записывай еду голосом за 10 секунд».
2. **Создание героя**: пол (м/ж), тон кожи (5 вариантов), причёска (3 на пол). Живое превью героя.
3. **Параметры**: рост, вес, целевой вес, возраст, уровень активности (4 варианта).
   Под формой — рассчитанная дневная норма калорий. Если цель ниже здорового ИМТ 18.5 —
   мягкое предупреждение и минимально допустимый вес, кнопка «Далее» неактивна.
4. **Ленивый режим — мои порции**: карточки «Моя тарелка», «Моя кружка», «Мой бутерброд»,
   «Моя ложка» со значением в граммах/мл и степперами −/+. Иллюстрации-иконки предметов.
5. **Разрешения**: микрофон и распознавание речи, Здоровье (шаги, сон, вес), уведомления —
   три карточки с объяснением «зачем» и кнопкой «Разрешить», можно пропустить.

### 2. Главный экран «Герой»
Сверху вниз:
- **Шапка**: бейдж уровня (число), титул («Новичок», «Странник»…), XP-бар с подписью «340 / 1000 XP»,
  монеты (иконка + число), серия дней (огонь + число), шестерёнка.
- **Герой** по центру, крупно, с лёгкой idle-анимацией (дыхание, моргание). Тап — гардероб.
- **Калории дня**: кольцо или полоса «1 240 из 1 900 ккал» + три мини-полосы БЖУ.
- **Быстрые шаблоны**: горизонтальный ряд из 3–5 чипов частых приёмов пищи
  («Овсянка с бананом · 320»). Тап = запись сразу, с наградой.
- **3 квеста дня**: компактные карточки (иконка, текст, прогресс «5 400 / 8 000 шагов», награда «+25 XP»).
- **Большая кнопка микрофона** внизу по центру над таб-баром (главный CTA, 72–80 pt),
  рядом маленькая иконка клавиатуры для текстового ввода.
- Если есть фразы, ожидающие сети: плашка «2 записи ждут интернета».

### 3. Голосовой ввод (оверлей поверх главного)
- **Слушаю**: затемнённый фон, пульсирующая кнопка, волна громкости, живая расшифровка
  крупным текстом («Я съел тарелку плова и два…»), кнопка «Готово», подсказка-пример мелким текстом.
- **Разбираю**: короткий скелетон/спиннер (≤ 3 с).
- **Не расслышал**: «Не расслышал, попробуй ещё раз» + кнопка «Ввести текстом».

### 4. Подтверждение записи (bottom sheet)
- Заголовок «Записываю» + исходная фраза серым.
- Список позиций: название, порция («1 тарелка · 300 г»), ккал, степпер −/+ для граммов.
  Позиции, где количество было угадано, помечены значком «≈».
- **Уточняющий вопрос** (максимум 2 на запись): «Шоколадка — сколько?» + чипы вариантов
  с калориями («Квадратик · 27», «Четверть плитки · 135», «Вся плитка · 540»). Предвыбран вариант по умолчанию.
- **Не нашёл**: «Не знаю, что такое „чучвара“» → «Убрать» / «Ввести ккал вручную».
- Итог: «~900 ккал · Б 35 · Ж 40 · У 95».
- Кнопки: главная «Записать · +10 XP», второстепенная «Отмена».

### 5. Награды и обратная связь
- **Тост записи**: «Записано: ~900 ккал · +10 XP», XP-бар в шапке плавно доливается.
- **Новый уровень**: модалка на весь экран — конфетти, герой в прыжке, «Уровень 5!», новый титул,
  разблокированные предметы (карточки), кнопка «Круто!».
- **Квест выполнен**: тост с галочкой и «+25 XP · +5 монет».
- **Сундук дня** (все квесты выполнены): модалка с открывающимся сундуком и монетами.
- **Достижение**: тост с бейджем.

### 6. Дневник
- Переключатель дней (стрелки + «Сегодня»), сводка дня (ккал/норма, БЖУ).
- Приёмы пищи карточками со временем; свайп или меню — «Изменить», «Удалить».
- Блок «Ждут интернета»: фразы со статусом и кнопкой «Разобрать сейчас».
- Пустое состояние: герой с тарелкой, «Пока пусто. Нажми на микрофон и скажи, что ел».

### 7. Прогресс
- **Вес**: сглаженная линия тренда + бледные точки реальных взвешиваний, период 1 мес/3 мес/всё,
  кнопка «Добавить вес», подпись «−2.4 кг с начала».
- **Калории vs норма**: столбцы за 7/30 дней с линией нормы.
- **Активность**: шаги по дням.
- **Эволюция героя**: горизонтальная лента стадий героя с датами.

### 8. Награды
- **Квесты дня** (подробно) + таймер до обновления.
- **Достижения**: сетка бейджей, закрытые — силуэтом с условием («Пройди 100 км»).
  Примеры: «Первая кровь», «Неделя силы», «Железная воля», «Марафонец».
- **Гардероб**: превью героя сверху; ниже вкладки «Одежда», «Аксессуары»;
  предметы с замком «Ур. 5» или ценой в монетах; кнопки «Надеть» / «Купить · 120».
- **Заморозка серии**: карточка «Спасти серию · 50 монет».

### 9. Настройки
- Профиль и параметры, «Мои порции», распознавание (сервер / офлайн, адрес сервера),
  Здоровье (статус синхронизации), уведомления (время напоминаний), тема (системная/тёмная/светлая),
  экспорт данных, **«Удалить все данные»** с подтверждением вводом слова.

## Герой (аватар) — самое важное для разработки

- Плоский векторный стиль, простые формы, без градиентов-сеток, фильтров и масок
  (рендерится через react-native-svg). Допустимы простые линейные градиенты.
- Единый viewBox **0 0 200 300**, герой в полный рост, ноги стоят на y≈285.
- **Слои** (отдельные группы `<g id="...">`, порядок снизу вверх):
  `shadow`, `legs`, `body`, `outfit-bottom`, `outfit-top`, `arms`, `head`, `face`, `hair`, `accessory`.
- **3 стадии телосложения** × 2 пола: `stage-0` (старт, мягкий силуэт), `stage-1`, `stage-2` (подтянутый,
  спортивный). Меняются только `body`, `legs`, `arms` и посадка одежды; голова одинаковая.
- Цвета кожи, волос и одежды — через переменные (`fill="var(--skin)"` или обозначь их в
  отдельной таблице), чтобы перекрашивать в коде. 5 тонов кожи, 6 цветов одежды.
- **Аксессуары за уровень**: ур. 3 — повязка на голову, ур. 5 — плащ, ур. 10 — корона/аура.
- **Позы**: `idle`, `cheer` (руки вверх, для level-up), `wave` (онбординг).

## Иконки

Единый набор 24×24, обводка 2 px, скругления: микрофон, клавиатура, XP (молния/звезда), монета, огонь серии,
сундук, квест, шаги, сон, вода, тренировка, вес, тарелка, кружка, бутерброд, ложка, замок, шестерёнка,
4 иконки таб-бара (активная и неактивная).

## Анимации

Таблица: элемент, триггер, длительность, easing. Минимум:
XP-бар доливается (600 мс, ease-out), цифра «+10 XP» всплывает и тает (900 мс),
level-up (конфетти 1.2 с, герой прыгает), кнопка микрофона пульсирует при записи,
сундук открывается, idle героя (дыхание 3 с цикл, моргание раз в 4–6 с).

## Формат результата (обязательно)

1. **Дизайн-токены** в JSON именно в такой структуре (значения — твои):
```json
{
  "color": {
    "dark":  { "bg": "", "surface": "", "surfaceAlt": "", "text": "", "textMuted": "", "border": "",
               "primary": "", "onPrimary": "", "xp": "", "coin": "", "streak": "", "success": "",
               "warning": "", "danger": "", "protein": "", "fat": "", "carbs": "" },
    "light": { "...": "те же ключи" }
  },
  "font": { "display": "", "body": "", "sizes": { "xs": 12, "sm": 14, "md": 16, "lg": 20, "xl": 28, "xxl": 40 } },
  "radius": { "sm": 8, "md": 12, "lg": 20, "pill": 999 },
  "space": [0, 4, 8, 12, 16, 20, 24, 32, 48],
  "shadow": { "card": "", "glow": "" }
}
```
2. **Макеты каждого экрана** из списка выше, тёмная и светлая тема, с подписанными компонентами.
3. **Список компонентов** (кнопки, карточки квеста, чип шаблона, позиция в подтверждении, тост, модалка,
   XP-бар, бейдж) — с состояниями: default / pressed / disabled / loading.
4. **SVG героя** по слоям, как описано выше: отдельные файлы или один файл с понятными `id`.
5. **SVG иконок** 24×24.
6. **Таблица анимаций**.
7. **Все тексты интерфейса** на русском (кнопки, пустые состояния, ошибки, тосты) — отдельным списком.

Если инструмент умеет генерировать код — делай **React Native (Expo) компоненты** на `StyleSheet`
и `react-native-svg`, без веб-специфики (никаких CSS grid, hover, `div`).
